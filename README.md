# Fleur de Lait — Boulangerie & Pâtisserie

Landing page desenvolvida individualmente para uma confeitaria fictícia de inspiração francesa, com foco em UI/UX, identidade visual e apresentação de produtos.

## Sobre o projeto

A proposta foi criar uma interface elegante para uma marca de confeitaria, trabalhando composição visual, hierarquia tipográfica, apresentação de produtos e experiência de navegação.

## Tecnologias e ferramentas

- HTML5
- CSS3
- Figma

## Destaques

- identidade visual inspirada em confeitaria francesa;
- composição de hero section e seções de produtos;
- uso de tipografia e imagens como elementos centrais da interface;
- CTAs voltados à simulação de uma experiência comercial;
- desenvolvimento com atenção à adaptação para diferentes tamanhos de tela.

## O que pratiquei

- transformação de uma proposta visual em código;
- estruturação de landing pages;
- HTML semântico;
- CSS com Flexbox e Grid;
- hierarquia visual e espaçamento;
- fundamentos de UI/UX aplicados ao Front-end.
