# Fleur-de-Lait
A Fleur de Lait é uma landing page conceitual desenvolvida para uma Boulangerie &amp; Pâtisserie fictícia de alto padrão, especializada em doces finos franceses, éclairs e bolos artesanais. O objetivo principal do projeto foi unir uma estética visual gastronómica sofisticada a técnicas avançadas de UI/UX focadas em conversão.
